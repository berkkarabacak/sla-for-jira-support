# SLA for Jira Software: support

Public support and issue tracker for **SLA for Jira Software**, an Atlassian Forge app for Jira Cloud by Berkly (berkly.nl).

## Documentation

**[Get started guide](GET-STARTED.md)**: your first SLA in 5 steps, calendars and timezones, pause and overrides, SLA fields in JQL, and what each Health line means.

## Report a bug or ask a question

[Open an issue](https://github.com/berkkarabacak/sla-for-jira-support/issues/new/choose) and pick **Bug report** or **Question**.

Please **do not post personal data or secrets** here: no names, email addresses, account IDs, issue contents, tokens or screenshots showing them. This tracker is public.

## Security and private matters

Report security issues, privacy requests and anything confidential by email to **info@berkly.nl**, not on this tracker.
