# SLA field

The app adds an **SLA** field to work items. It shows one line per SLA, worst first: the status and the time, for example **Breached** *Overdue 2d 4h · Time to triage*. The SLAs come from the project's settings, so the field has nothing to edit: in edit mode it says *Set by the project's SLAs.*

> **Tip:** Add the field to your screens in Jira's field configuration if it does not appear.
