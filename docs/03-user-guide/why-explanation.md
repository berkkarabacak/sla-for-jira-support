# History

Every timer has **History**: select it under an SLA in the panel, or on a row of [All timers](all-timers.md). It shows how the timer got where it is:

- **Started**, **Worked** and **Due** (or **Finished**): when it started, how much working time it has used of its target, and its deadline. The ⓘ beside **Worked** shows the sum.
- Every event, newest first: started, paused, resumed, extended, excluded, at risk, breached, stopped. Each says when, who, and the reason they gave.

The working hours, their timezone and which target applied (for example by priority) are in the ⓘ beside the SLA's name.

> **Tip:** History and the project's **Activity** tab show each event the same way, so you can compare them line by line.
