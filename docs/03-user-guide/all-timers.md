# All timers

Every timer in the project, finished ones included. **State** filters the list: All, Breached, At risk, On track, Paused, Met, Missed or Excluded.

Columns: Status · Work item · SLA · Progress (a bar and the time used against the target, such as *17d 16h / 4h*) · Result (*3h 20m left* with the deadline, *Overdue 2d 4h*, *Met in 43m*) · **History**, which opens that timer's [History](why-explanation.md).

**Export CSV** shows the rows as text: select all and copy them into a spreadsheet.
