# Projects

The **Projects** tab lists every project that measures SLAs:

| Column | Shows |
|---|---|
| Project | Key and name. |
| SLAs | The project's SLA names (three, then "+n"). |
| Working hours | The working hours the project uses. |
| On track | Running timers that have not breached. |
| Breached | Breached timers, in a red badge. |
| Status | **On** or **Off**. A refresh icon means a job is running. |

The **⋯** menu on each row has **Open settings**, **Apply to existing work items** (see [Backfill](backfill.md)) and **Turn off** / **Turn on**. Turning a project off keeps its timers.

To add SLAs to another project, choose it in **Add SLAs to a project** and select **Set up**.
