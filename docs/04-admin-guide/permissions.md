# Permissions and licensing behaviour

| Who | Can |
|---|---|
| Jira admins | Everything on the site-wide admin page. |
| Project admins | Edit the project's SLAs and working hours. Everyone else sees them as **View only**. |
| Everyone with browse access | See timers and use the panel. |

If a paid licence becomes inactive, the app goes **read-only**: timers keep showing and no data is lost; changes are blocked until the licence is active again. See [Licensing](../08-licensing/README.md).

App scopes are listed in [Scopes](../07-data-security-privacy/scopes-and-permissions.md).
