# Site-wide admin page

**Jira settings (⚙) → Apps → SLA**. Jira admins only.

The header has the app name, **Get started** and **Docs**, and counts of projects, SLAs, timers and breached timers.

| Tab | Page |
|---|---|
| Projects | [Projects](projects.md) |
| Working hours | [Working hours](calendars.md) |
| JQL | [JQL](jql-fields.md) |
| Health | [Health](health.md) |

There is no **Goals** tab any more: each project's SLAs are listed on **Projects**. The privacy, data and support links are under **Health → Data & privacy**.
