# See your first result

1. Create a work item in the project, or move one into the SLA's start condition.
2. Open it. The **SLA** panel shows the status, the time left (for example *3h 20m left*) and when it is due.
3. Open the project sidebar → **SLA** to see it under **All timers**.
4. Within a few minutes, try JQL: `slaState = "ok"`.
