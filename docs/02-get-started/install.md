# Install the app

1. In Jira, open **Apps → Explore more apps** and search for **SLA for Jira Software**, or open the [Marketplace listing](https://marketplace.atlassian.com/apps/39044805).
2. Select **Get it now** and approve the permissions (see [Scopes](../07-data-security-privacy/scopes-and-permissions.md)).
3. When the install finishes, open **Jira settings (⚙) → Apps → SLA get started**.

> **Note:** The app works on **Jira Software** (company-managed and team-managed) projects. Its panel and project page only appear in software projects.
