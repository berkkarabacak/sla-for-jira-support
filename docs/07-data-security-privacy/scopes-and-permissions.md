# Scopes and permissions

| Scope | Why |
|---|---|
| `read:jira-work` | Read work items, changelogs and search (events, backfill, previews). |
| `write:jira-work` | Write the JQL index properties and optional breach comments and labels. |
| `read:jira-user` | Read your timezone for the default calendar and refresh display names. |
| `report:personal-data` | Report stored account IDs to Atlassian and erase closed accounts. |
